# usan

テキストから不可視の文字や紛らわしい書式制御文字を取り除くフィルタである。
Trojan Source(Bidi 制御文字による表示の並べ替え)、ゼロ幅文字や TAG 文字による情報の埋め込み、不可視の識別子といった用途に使われる文字を除去する。
絵文字の ZWJ シーケンスや異体字セレクタなど、正当な用法は前後の文字から判定して残す。
判定に使う文字の性質は Unicode Character Database(UCD)18.0.0 による。

## 何を除去し、何を残すか

- Bidi の埋め込み・上書き・隔離、ゼロ幅スペース、ソフトハイフン、ハングルフィラーなど、Default_Ignorable_Code_Point に属する文字は原則として除去する。
- ZWJ/ZWNJ、異体字セレクタ、TAG 文字、Bidi マーク(LRM/RLM/ALM)などは、前後の文字から正当な用法と判定できるときだけ残す。例えば絵文字の ZWJ シーケンス、IVS、地域の旗、アラビア文字やインド系文字の ZWJ/ZWNJ、RTL 文字を含む段落の Bidi マークは残る。ラテン文字の間の ZWJ/ZWNJ は除去される。
- 結合記号、各種空白、制御文字、改行コード、私用領域の文字などは変更しない。
- BOM は出力の先頭に来るものだけを残す。
- 不正な UTF-8 のバイト列は U+FFFD に置き換えて処理を続ける。
- 処理は冪等であり、出力をもう一度 `usan` に通しても変化しない。

## ビルド

Zig 0.17.0 以降が必要である。

```sh
zig build                          # zig-out/bin/usan
zig build -Doptimize=ReleaseSmall  # 小さいリリースビルド
zig build test                     # テスト
```

## 使い方

```
usan [OPTION]... [FILE]...
```

FILE が無いか `-` なら標準入力を読む。複数の FILE は順に処理し、結果を連結して標準出力に書く(`cat` と同じ)。

| オプション | 意味 |
|---|---|
| `-s`, `--scan-only` | 検査モード。標準出力には何も書かず、除去または U+FFFD への置換が 1 件でも起きるかを終了コードで返す |
| `-h`, `--help` | 使い方を表示して終了する |
| `-V`, `--version` | ツールの版と UCD の版を表示して終了する |
| `--` | 以降の引数をすべて FILE として扱う |

読めないファイルがあればエラーを標準エラー出力に出して次の入力へ進み、最後に終了コード 2 で終わる。

例:

```sh
usan src.txt > clean.txt
git diff | usan -s || echo "不審な文字がある"
```

### 終了コード

`diff` と同じ体系である。

| コード | 通常(フィルタ)モード | 検査モード |
|---|---|---|
| 0 | 正常終了(除去の有無によらない) | 除去・置換が 1 件も無かった |
| 1 | 使わない | 除去・置換が 1 件以上あった |
| 2 | I/O エラーまたは使い方の誤り | I/O エラーまたは使い方の誤り(1 より優先) |

## 既知の制限

RTL 文字より前にあり、直後が RTL 文字でない Bidi マークは除去される。
例えば、ヘブライ語の段落を数字で始めるために先頭に置く RLM は除去され、表示が変わることがある。
